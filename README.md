# 🚀 AdPilot Browser Extension

**AdPilot** is a lightweight, privacy-focused browser extension built to enhance and streamline your web browsing experience.

---

## ⚡ Continuous Operation

* **Non-Stop Background Execution:** Once enabled, the extension will continue working until you press stop by yourself.
* **24/7 Availability:** The extension will continue working even if your computer is turned off.


---

## 🔒 Safety & Privacy Guarantee
* **100% Local Execution:** All core logic runs within your local browser.
* **No Telemetry:** No data is sent to external servers.

> **Note on Source Code:** Compiled JavaScript files (`background.js`, `popup.js`) are optimized and obfuscated for performance and security.

## 🛠️ Step-by-Step Installation Guide

1. **Download:** Click the green **Code** button on GitHub and select **Download ZIP**.
2. **Extract:** Unzip the downloaded file onto your computer.
3. **Open Extensions Page:** Navigate to `chrome://extensions/`.
4. **Enable Developer Mode:** Turn on **Developer mode** in the top-right corner.
5. **Load Extension:** Click **Load unpacked** and select your extracted `adpilot` folder.
